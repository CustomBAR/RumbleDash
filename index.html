What you get

Everything a streamer needs, nothing else.

Live counters

Follower and subscriber counts are pulled from the Rumble API with a five second cache and land in the app and your widgets instantly.

Goal progress

Set a follower goal and a subscriber goal, then watch the bars fill. The dashboard shows the percentage, the widgets show the bar.

Native desktop app

Version 3 is written in Rust with egui: a charcoal interface, one ember accent and no browser in sight.

Drop-in config

config.json is byte-compatible with v2 and every v2 endpoint is preserved, so your existing setup keeps working.

OBS widgets

Copy the URL. Done.

Add a Browser source in OBS and paste one of these. The widgets are compiled into the binary, so they work from any folder and any machine.
