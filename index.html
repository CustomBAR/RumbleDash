What makes RumbleDash awesome?

Real-time analytics

Follower and subscriber counts are polled from the Rumble API with a five second cache and appear instantly in the app and in your widgets.

Goal progress

Set a follower goal and a subscriber goal, then let the progress bars do the talking – in the app and on your stream.

Native desktop app

Version 3 is written in Rust with egui: a charcoal interface, a single ember accent and no browser required.

OBS widgets

Copy the widget URL and paste it into an OBS browser source. The widgets are built into the binary, so they work from any folder.

Drop-in configuration

config.json is byte-compatible with v2. Point the app at your existing file and carry on where you left off.

Headless option

Prefer no window? Run the embedded server on its own and let it feed your widgets around the clock.
